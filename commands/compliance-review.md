# /compliance-review

Run advisory regulatory triage. Establish what the user is building and their users'
jurisdictions, then work `skill/regulatory.md` (securities, AML/KYC, Travel Rule,
jurisdiction-specific regimes) and, if a token is being designed,
`skill/token-2022-compliance.md`. Output flags and open questions for counsel. Never
declare the user "compliant."
